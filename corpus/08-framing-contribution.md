# 08 — Freedom and contribution

## Current
- **[ploki]** Someone working on a maieutics project should be able to **specialise the skill** — a branch in a repository elsewhere, a pull request back. **Freedom and contribution.**
- **[ploki]** Two kinds of branch, and they are not the same thing:
  - **correction and efficiency branches** — someone found a bug, or simply found better. These come back;
  - **disciplinary specialisation branches** — maieutics for law, for research, for writing. **To be specified later; nothing is decided here.**
- **[ploki]** **A `CONTRIBUTING.md` is a good idea.**

## Why this follows from what is already decided [opus-5]
Decision #11 settled that `partus/` is the source and the installation a copy. The consequence had not been drawn: anyone running the skill on a real project will eventually want to bend it, and today their improvement can only live in their own `~/.claude/skills/` and die there. A contribution path is what turns a personal fix into a shared one.

The two kinds of branch behave differently, which is why they should not share a mechanism:
- **corrections come back.** They are about the same skill doing the same thing better, so a pull request is the right shape and the repository only needs to say what a good one looks like.
- **specialisations diverge.** A maieutics for law and a maieutics for worldbuilding will not converge, and trying to merge them produces a skill that serves neither. Whether they become acknowledged forks, variants inside the repository, or overlays that change only what is theirs, is an open design question.

## Still open

- What a `CONTRIBUTING.md` should ask for. A first list **[opus-5]**: that a change to `SKILL.md` be argued, not just asserted; that it be tried on a real project before being proposed; that the proposer say which project, since the method's value is only visible in use; and that the decision log of that project be the evidence, which is a contribution requirement no other repository can make.
- Whether contributions to the **French original** are accepted, or whether `SKILL.fr.md` is frozen.
