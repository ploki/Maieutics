# 08 — Freedom and contribution

## Current
- **[ploki]** Someone working on a maieutics project should be able to **improve the skill** — a branch in a repository elsewhere, a pull request back. **Freedom and contribution.**
- **[ploki]** **There must be no specialisation. Thought is general.** A maieutics for law, one for research, one for fiction: no. **The specialisation forms during the exercise with the model**, not in the method.
  - ↺ *The agent had proposed two kinds of branch, corrections and disciplinary specialisations, and left the second "to be specified later". The author refused the idea outright on 2026-10-03.*
- **[ploki]** So what comes back are **corrections and efficiency** branches.
- **[ploki]** **A `CONTRIBUTING.md` is a good idea** — written on 2026-10-03.

## Why the refusal is right [opus-5]
- **It is what the method already claims.** The skill knows nothing about any subject. It asks, it writes down, it tracks reversals. Nothing in it would change for a lawyer, because nothing in it is about law. A specialised variant would have to invent a difference that is not there.
- **The specialisation is in the corpus, and that is the point.** A project on hard SF and a project on a skill have, after a day, utterly different glossaries, note types and deliverables — and they were produced by the same unaltered instructions. The method stays general precisely so that each exercise can become particular.
- **It keeps the repository alive.** Variants fork and die; a single general skill accumulates every correction anyone makes. The thing that would have fragmented the project is now refused in writing.
- **And it answers the oldest question in the corpus**, the one left open in note 02 about whether the created file names should follow the user's language: a general method has one vocabulary. Variants would have reopened it on every axis at once.

- **[ploki]** That a contributor has run the method themselves **is implied**: the `CONTRIBUTING.md` asks for the decision log of the project the change was tried on; nothing more is needed (decision #87).
- **[ploki]** **`agora` belongs here: it is general enough** (2026-10-06, decision #109).
  - **[opus-5.5]** It adds a shape of project — a hub sessions start from and return to — not a domain.
