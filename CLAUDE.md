This folder is a maieutics project about the maieutics skill itself.

The corpus lives in `corpus/`, deliverables in `partus/`, scripts in `instrumenta/`, abandoned material in `archive/`. Read `corpus/author-intent.md` first.

All outputs are in English.

**Working rule:** never modify the installed skills in `~/.claude/skills/`. The skill under development lives in `partus/`. While working here, adapt the session's own behaviour to the repository's version of the skill — re-read `partus/maieutics/SKILL.md` before relying on it, since the session started from the installed copy.
